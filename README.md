# EmbodyRSI

让 Agent 做具身模型的研发工程师：从执行记录推断能力缺口，改数据、环境与架构。

Agent 读具身模型执行后留下的完整记录（多视角视频与数值），推断模型欠缺哪些能力、或者仿真环境本身有什么缺陷，然后修改模型的研发管线：训练数据的生产方式、仿真训练环境与资产、观测模态与模型结构、训练配方。每一轮迭代产出的是一个更好的研发配置，而不是直接更新模型参数。

我们已经在空中操作基准 [AM-Bench](https://arxiv.org/abs/2609.00641) 上由人加 AI 手工跑通了一次这个闭环：π₀.₅ 的 12 任务宏平均从论文的 52.2 提升到 56.7；三个脚本专家成功率为 0 的任务查出都是仿真环境缺陷，修复后专家可用。本仓库记录这段过程，并为自动化这一闭环做准备。

**新成员请先读 [`docs/交接说明.md`](docs/交接说明.md)。**
