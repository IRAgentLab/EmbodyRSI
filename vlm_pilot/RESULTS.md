# VLM 失败理解先导实验：结果

2026-09-26。实验设计见 `README.md`，评分标准见 `scoring/INSTRUCTIONS.md`，完整分表见 `scoring/summary.md`。

## 结论

1. **能看见现象，但判断不了原因。** 在环境缺陷组，模型经常能说出失败的现象，但几乎从不说出真正的根因。207 条回答里只有 5 条指出"物体其实从一开始就没有被真正抓住"：WipeWindow 3 条，TossBall 2 条，FrameAssembly 0 条。
2. **分不清环境问题和策略问题。** 在诊断类提示词下：
   - 真正的环境缺陷被归到环境侧的比例是 24–39%；
   - 真正的策略失败被误判为环境问题的比例是 28–37%。

   两组的比例几乎一样，说明归因没有依据画面证据，接近随机。
3. **提示词只能小幅改善。** 通用检查清单（`P3`）和"排除一侧需给证据"的版本（`P3b`）都没有提高根因命中率。`P3b` 让策略失败组的误判略降（37% → 28%），正确归因略升（50% → 56%），但样本小，差异在误差范围内。强制每侧至少两个假设（`P3`）让策略失败组的"两者都有"判断从 11% 升到 19%。
4. **视频不比关键帧好。** 同一模型用视频输入时更倾向于归到环境侧，但根因命中率没有提高。
5. **开放描述幻觉很多。** 不给具体问题、只让模型描述时，幻觉率为 38–83%。常见的是编造物理上不可能的事件：无人机坠毁、物体凭空消失、同一物体同时出现在两处、机械臂穿墙。
6. **人的判断靠的是"这不合理"的先验。** 人当时说"夹爪一直是紧的，但框会滑脱，很不合理"，模型在 FrameAssembly 上 72 条回答里 0 条这样说。这类先验判断，恰恰是现有 VLM 缺的。

对研究规划的含义：**单靠 VLM 看视频，即使加上检查清单，也做不到"区分环境缺陷与能力缺口"。** 这支持规划里的方案：必须给诊断者数值状态（例如夹爪开度 0.002 表示什么都没夹住）、仿真特权视角和探针实验，而不是只优化提示词。

## 这次实验的局限

- **成功组无效。** 仿真在任务成功的那一刻自动 reset，录制随之停止：TossBall 成功视频的最后一帧里球还在空中，FrameAssembly 成功视频结束时夹爪还夹着框。模型判为"未完成"有合理依据，所以成功组 90% 以上被判为失败的结果不代表误报率。要测误报，需要在成功后多录 1–2 秒重新做这一组。
- **Kimi 数据不全。** Moonshot 账户余额不足、并发受限，P3 只完成 15/72，P3b 为 0。结论主要基于 DeepSeek 与 Qwen。
- **样本小。** 每个案例 2 集，每条件重复 2 次，单元格 n 为 10–60，比例差异在 10 个百分点以内的都不应解读。
- **评分由 LLM 完成，未经人工复核。** 每条回答只有一位评分者，建议抽取 10–20% 由人复核，并计算一致性。
- **提示词是在已知答案后写的。** 检查清单可能偏向这三种缺陷，需要在未见过的缺陷类型上验证。
- **案例覆盖窄。** 三个环境缺陷的根因碰巧同类（物体没有真正被抓住），不能代表所有环境缺陷。

## 下一步建议

1. 重录成功组：成功后继续录 1–2 秒，重测误报率。
2. 做证据分级：在同一案例上依次加入数值状态（夹爪开度、物体与末端的相对位置）、仿真特权视角（碰撞体、接触力）、探针实验，测每一级带来的根因命中率提升。这是规划里的核心实验。
3. 注入新的缺陷类型（错误摩擦、目标缺碰撞体、错误判定区、错误初始位姿），构建诊断基准，同时检验提示词是否只对已知案例有效。
4. 人工复核一部分评分，报告评分一致性。
5. Kimi 充值后以低并发补跑，作为第三个模型的完整对照。
